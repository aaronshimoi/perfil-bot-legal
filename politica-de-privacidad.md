Esta política explica cómo funciona la privacidad del bot de Discord **[dks]** (el “Bot”), que crea tarjetas de perfil al usar `/perfil`.

## 1. Datos que procesa

Cuando ejecutas `/perfil`, el Bot procesa:

- El nombre y los campos opcionales que escribes: biografía, Instagram, Roblox, juego o artista, y nivel de batería social.
- El identificador, nombre de usuario y avatar de Discord asociados con la interacción, para identificar al autor y crear la tarjeta.
- Información técnica necesaria para recibir la interacción y responder en el servidor, como el servidor y canal donde se ejecutó el comando.

No solicites ni incluyas contraseñas, datos financieros, información médica ni datos privados de otras personas.

## 2. Para qué se usan los datos

Los datos se usan únicamente para procesar el comando, generar la imagen y responder en el servidor. El código actual no mantiene una base de datos ni guarda de forma permanente los campos del perfil. Los datos se procesan temporalmente mientras se genera la imagen. La imagen resultante se publica en Discord y queda sujeta a las funciones de almacenamiento y retención de Discord.

El Bot puede producir registros técnicos de errores para diagnosticar fallos. Si el Bot se aloja en un proveedor externo, ese proveedor puede procesar datos técnicos necesarios para operar el servicio conforme a sus propias condiciones y políticas. Completa aquí el proveedor de alojamiento antes de publicar si usarás uno: **[PROVEEDOR DE ALOJAMIENTO O “NO APLICA”]**.

## 3. Compartición

El Bot no vende datos ni los usa para publicidad. Comparte con Discord la respuesta necesaria para publicar la tarjeta en el servidor, conforme a la plataforma y sus reglas. Las personas con acceso al canal pueden ver la imagen y copiarla o conservar una captura.

Discord procesa información de acuerdo con su propia [Política de Privacidad](https://discord.com/privacy). El proveedor donde alojes el Bot también puede tener acceso técnico a registros del servicio; consulta su política correspondiente.

## 4. Conservación y eliminación

El código actual no guarda los campos enviados en una base de datos. Si quieres retirar una tarjeta publicada, puedes borrar el mensaje en Discord si tienes permiso para hacerlo, o pedir ayuda a la moderación del servidor. Borrar el mensaje no elimina copias, capturas ni datos que Discord conserve de acuerdo con sus políticas.

Para consultas o solicitudes relacionadas con datos procesados por el Bot, contacta a **[aaronmoshi01@gmail.com]** e indica tu usuario de Discord y el servidor donde usaste el comando. No envíes tu token, contraseña ni datos sensibles. Si incorporas almacenamiento persistente en el futuro, esta política deberá actualizarse para describir los datos, plazos y método de eliminación reales.

## 5. Seguridad y menores

Se aplican medidas razonables para proteger la configuración y las credenciales del Bot. El token del Bot debe mantenerse secreto y no incluirse en mensajes, tarjetas ni repositorios públicos.

El Bot no está diseñado para recopilar deliberadamente datos de menores. Su uso está sujeto a los requisitos de edad y las reglas de Discord aplicables en tu lugar de residencia.

## 6. Cambios y contacto

Podemos actualizar esta política cuando cambie el Bot o la forma en que procesa información. La versión vigente estará publicada en esta página con su fecha de actualización. Para preguntas sobre privacidad, escribe a **[aaronmoshi01@gmail.com]**.

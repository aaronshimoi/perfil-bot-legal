Estas condiciones regulan el uso del bot de Discord **[dks]** (el “Bot”), que genera una tarjeta de perfil como imagen cuando una persona usa el comando `/perfil`.

## 1. Aceptación y requisitos

Al usar el Bot, aceptas estas condiciones y las reglas de Discord. Si no estás de acuerdo, no uses el comando. Debes tener edad suficiente para utilizar Discord según las reglas aplicables en tu lugar de residencia.

## 2. Qué hace el Bot

El Bot toma el nombre, la biografía, los enlaces o intereses y el nivel de batería social que incluyas en `/perfil`. También usa tu nombre de usuario y avatar de Discord para componer una imagen. Publica esa imagen como respuesta al comando en el servidor donde lo ejecutaste.

El Bot no cambia tu perfil de Discord ni verifica que los enlaces o datos sean verdaderos. La persona que ejecuta el comando es responsable de lo que introduce y comparte.

## 3. Uso permitido

No uses el Bot para publicar contenido ilegal, amenazante, abusivo, que infrinja derechos de otras personas o que viole las reglas de Discord. No incluyas contraseñas, datos financieros, información médica ni otra información privada en la tarjeta. No intentes interferir con el funcionamiento del Bot ni usarlo para acosar o suplantar a alguien.

Podemos dejar de ofrecer el Bot o limitar su uso si es necesario para proteger a las personas usuarias, el servicio o el cumplimiento de estas condiciones y de las reglas de Discord.

## 4. Tus datos y contenido

Conservas la responsabilidad por el contenido que envías. Al usar el comando, autorizas al Bot a procesarlo para generar la tarjeta y publicarla en el canal como respuesta. Asegúrate de tener permiso para usar cualquier imagen o texto que incluyas.

La tarjeta puede ser visible para otras personas del servidor y quedar sujeta a las funciones de almacenamiento, captura, copia y moderación de Discord. Consulta la [Política de Privacidad](politica-de-privacidad.html) y la [política de privacidad de Discord](https://discord.com/privacy).

## 5. Disponibilidad y responsabilidad

El Bot se ofrece tal como está disponible. No garantizamos que funcione sin interrupciones, errores o pérdida de disponibilidad. En la medida permitida por la ley aplicable, dks no será responsable por daños indirectos derivados del uso del Bot. Nada de esta sección limita responsabilidades que no puedan excluirse legalmente.
